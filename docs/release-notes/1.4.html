Flipper 1.4

Updates from inside the app, a disk image to download, and Intel Macs.

  • This is the last version you download by hand. To update from 1.3, quit Flipper, open the DMG and drag Flipper into Applications, replacing the old copy. From now on, updates come through the app.
  • Flipper checks for updates once a day and shortly after it opens, and asks before installing anything. Check for Updates… looks now, and Check for Updates Automatically turns the checking off. Checking for updates is the only time Flipper goes online. Both items show once Flipper is in Applications.
  • Flipper runs on Intel Macs too. Earlier versions ran only on Apple silicon.
  • Flipper needs macOS 15 or later.
  • While Flipper needs Accessibility, its menu bar icon gets a red dot instead of dimming, so you can still tell which app it is. The icon still dims with every switch off, since Flipper isn't changing anything then.
  • Opening Flipper again while it runs, from Applications or Spotlight, opens its menu. Before, nothing happened.
